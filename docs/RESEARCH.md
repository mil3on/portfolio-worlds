# Исследование готовых решений

Проверено 17 октября 2026 года. Ниже — не абстрактный список движков, а варианты, применимые к небольшой браузерной 3D-планете с персонажем от третьего лица.

## Рекомендация: React Three Fiber + Rapier + ecctrl

Для этого прототипа это самый короткий и гибкий маршрут.

- [Three.js AnimationMixer](https://threejs.org/docs/pages/AnimationMixer.html) воспроизводит клипы анимации, а [animation system](https://threejs.org/manual/pages/animation-system.html) описывает работу с `GLTFLoader` и переходами между `idle`, `walk`, `run` и `jump`.
- [Rapier character controller](https://rapier.rs/docs/user_guides/javascript/character_controller/) рассчитан на кинематического персонажа, коллизии, ступени и склоны. Он требует, чтобы игра сама передавала вектор гравитации — это как раз полезно для сферического мира.
- [ecctrl](https://github.com/pmndrs/ecctrl) — готовая надстройка для React Three Fiber и Rapier. В документации есть `custom gravity`, контроллер камеры, touch-управление и состояния анимаций; API прямо содержит `setUp` для сцены с необычной осью «вверх».

**Вывод:** берём этот стек для первой реализации. Не нужно писать собственный контроллер с нуля.

## Другие жизнеспособные варианты

| Вариант | Когда выбрать | Почему не первый выбор сейчас |
| --- | --- | --- |
| Babylon.js + Havok | Нужен движок «из коробки» и меньше React | Хорош для самостоятельной игры, но хуже интегрируется с привычной React-структурой портфолио. |
| PlayCanvas | Нужен визуальный редактор сцены в браузере и совместная работа | Удобен для художников, но добавляет отдельный редактор и пайплайн, избыточные для трёх небольших локаций. |
| Godot Web export | Игра перерастает сайт и требует полноценного игрового редактора | Web-сборка тяжелее, а HTML-интерфейс кейсов интегрируется менее естественно. |

## Планета «как Земля»

Для внешнего вида использовать [NASA Blue Marble](https://visibleearth.nasa.gov/collection/1484/blue-marble) / [Blue Marble: Next Generation](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/). Это спутниковая мозаика Земли, подготовленная NASA. В MVP достаточно одной сжатой дневной текстуры 2K–4K; облака и ночные огни лучше подключать только после замеров производительности.

Нужно хранить источник и проверять условия использования конкретно скачанного файла перед публикацией. Отдельный файл `ATTRIBUTIONS.md` будет добавлен вместе с реальными ассетами.

## Персонаж и анимации

Использовать модель в `GLB` (вариант glTF) с отдельными клипами `idle`, `walk`, `run`, `jump` или клипами с одинаковым скелетом. Важно проверять лицензию каждого файла до добавления в репозиторий — не скачивать ассеты «по умолчанию» из случайных наборов.

## Что проверяем в самом первом техническом спайке

1. Проходит ли персонаж полный круг по сфере без переворота камеры и дрожания модели.
2. Можно ли сохранить 60 FPS при планете, одном персонаже и трёх простых ориентировочных локациях.
3. Остаётся ли карточка кейса читаемой и не мешает ли ей 3D-движение.

Если все три ответа положительны — продолжаем наполнять мир. Если нет, уменьшаем амбицию до стилизованной планеты с отдельными островками, сохраняя идею интерактивной карты кейсов.
