# Portfolio Worlds

Тестовая 3D-среда для портфолио: персонаж от третьего лица исследует небольшую Землю и приходит в тематические локации-кейсы.

Это отдельный эксперимент, поэтому он не меняет основной сайт до тех пор, пока механика и производительность не будут проверены.

## Что будет в первом прототипе

- мини-планета с визуальной основой NASA Blue Marble;
- один управляемый персонаж: ходьба, бег, прыжок, поворот камеры мышью;
- три локации вокруг планеты: `Origin`, `UI Systems`, `Motion`;
- вход в локацию открывает аккуратную карточку кейса, а не ведёт на новую страницу;
- клавиатура и базовое управление на телефоне;
- загрузка за разумное время на обычном ноутбуке.

Подробный маршрут находится в [docs/PLAN.md](docs/PLAN.md), техническое исследование — в [docs/RESEARCH.md](docs/RESEARCH.md).

## Предлагаемый стек

`Vite + React + TypeScript + React Three Fiber + Rapier + ecctrl`.

`ecctrl` уже даёт физический контроллер от третьего лица и режимы нестандартной гравитации — это особенно удобно для ходьбы по сфере. Финальный формат моделей — `glTF/GLB`.
